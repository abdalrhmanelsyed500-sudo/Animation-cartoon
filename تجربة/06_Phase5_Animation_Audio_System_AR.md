# المرحلة 5: النظام الحركي والصوتي
## (Animation & Audio System) — «رحلة الجد صوفان»

> **ما تغيّر جذرياً في هذه المرحلة:**
> في المرحلة 4-ب أثبتّا أن الأصول **طبقات منفصلة**. في المرحلة 5 بنينا **المحرك الذي يحرّك تلك الطبقات**
> و**النظام الذي يزامنها مع الصوت**. كل شيء هنا يعمل فعلياً ويُخرج فيديو — وليس وصفاً نظرياً.

---

## 1. مكوّنات النظام (كلها في `تجربة/production_engine/`)

| الملف | وظيفته |
|---|---|
| `rig_engine.py` | **محرك التحريك**: شجرة مفاصل هرمية، تحويلات هندسية، استيفاء الإطارات المفتاحية، منحنيات تسهيل |
| `motion_cycles.py` | **مكتبة الحركات**: مشية الخراف، خبب الجرو، التنفّس، اهتزاز الذيل |
| `audio_lipsync.py` | **مزامنة الشفاه**: تحليل الصوت → تبديل طبقات الفم إطاراً بإطار |
| `audio_ambience.py` | **الصوت المحيطي والمؤثرات**: 5 طبقات إجرائية + مزج مع تفادي التغطية (Ducking) |
| `render_shot.py` | **مُصيِّر اللقطة**: يجمع الخلفية + القاطرة + الشخصيات في لقطة قابلة للتكرار |
| `mix_master.py` | **المزج النهائي** ودمج الصوت مع الفيديو |

### 1.1 محرك التحريك — كيف يعمل

```
timeline.json (أرقام فقط)
        ↓
   Track.value_at(frame)          ← استيفاء + منحنى تسهيل
        ↓
   Rig.solve(pose)                ← حلّ الشجرة الهرمية (الأب قبل الابن)
        ↓
   لكل مفصل: تدوير الجزء حول نقطة ارتكازه (Pivot)
        ↓
   ترتيب الرسم حسب العمق: back → mid → front → face
        ↓
      إطار PNG
```

**منحنيات التسهيل المدعومة:** `linear` · `in` · `out` · `in_out` · `smooth` · `out_back` · `elastic`

**الترتيب الطبولوجي:** يُحلّ المفصل الابن بعد أبيه دائماً (ترتيب عكسي آمن حتى لو كُتبت العظام بترتيب عشوائي).

## 2. الشجرة الهرمية للمفاصل

```
الجذر: الحوض (Pelvis)
 │
 ├── ساق خلفية          pivot [45, 20]   (depth: back  — معتمة بنسبة خفيفة للعمق)
 ├── الجذع + الملابس     pivot [120,175]  (depth: mid)
 │    ├── ذراع خلفية     pivot [45, 24]
 │    └── الرقبة        offset [0, -127]
 │         └── الرأس     pivot [120,172]
 │              ├── العينان   (طبقة قابلة للتبديل: open / blink)
 │              ├── الحاجبان  (طبقة مستقلة)
 │              └── الفم      (طبقة قابلة للتبديل: 5 أشكال)
 ├── ساق أمامية          pivot [45, 20]
 └── ذراع أمامية         pivot [45, 24]
```

**سمسم (الجرو) يضيف ثلاثة مفاصل غير موجودة عند الخراف:**
- `tail` — ذيل مستقل `pivot [70,78]`، يهتزّ بدورة 10 إطارات
- `ear_front` / `ear_back` — أذنان مستقلتان `pivot [35,18]`

## 3. مكتبة الحركات الجاهزة

| الدورة | الطول | من | الخصائص |
|---|---|---|---|
| `sheep_walk` | 24 إطار | صوفان / سلمى / فارس | الساقان خارج الطور 180°، الذراعان عكسياً، هزّة جسم مرتين |
| `puppy_trot` | **16 إطار** | سمسم | **أسرع بـ1.5×**، نطّة ±15px مقابل ±7px، ميل جذع ±5° مقابل ±2.5°، + ذيل + أذنان |

## 4. نظام مزامنة الشفاه (Lip-Sync) — تحليل صوتي حقيقي

### 4.1 الطريقة (ليست تخميناً)

1. **الطاقة (RMS)** لكل نافذة 40 مللي ثانية → هل الفم مفتوح؟
2. **تقدير الفورمنتات F1 و F2** عبر ترميز التنبؤ الخطي (LPC) بخوارزمية Levinson-Durbin،
   ثم إيجاد جذور كثير الحدود → التردد وعرض النطاق
3. **شجرة قرار فيزيولوجية** على الحركات العربية:

| الحركة | F1 | F2 | طبقة الفم |
|---|---|---|---|
| أ (فتحة) | ≈ 800 Hz | ≈ 1200 Hz | `part_mouth_open_A` |
| و (ضمة)  | ≈ 330 Hz | ≈  750 Hz | `part_mouth_open_O` |
| ي (كسرة) | ≈ 290 Hz | ≈ 2200 Hz | `part_mouth_open_E` |
| صمت | — | — | `part_mouth_closed_smile` |

4. **استمرار بعد الصمت (Hangover)** 80 مللي ثانية — يمنع إغلاق الفم بين المقاطع المتلاصقة
5. **رمش عشوائي طبيعي** كل 2.5–5 ثوانٍ، ببذرة ثابتة (قابل للتكرار)

### 4.2 التحقّق — بأرقام حقيقية

اختبرنا النظام على **صوت مُخلَّق بالفورمنتات نعرف حقيقته مسبقاً** (11 مقطعاً: أ / صمت / و / صمت / ي / صمت / أ / و / صمت / ي / صمت).

| المقياس | النتيجة |
|---|---|
| **الدقّة على المقاطع المتكلَّمة** | **100.0%** (34/34 إطار) |
| الدقّة باستبعاد لحظات الانتقال (±60ms) | 89.1% (41/46) |
| الدقّة الإجمالية (بما فيها حواف الصمت) | 77.0% (57/74) |

> **بصراحة:** الحالة الوحيدة التي ينخفض فيها الأداء هي **حواف المقاطع** (أول وآخر 60 مللي ثانية)،
> حيث تختلط نهاية مقطع ببداية الذي يليه. وهذا مقبول بصرياً لأن العين لا تلاحظ إطاراً واحداً،
> ويمكن تحسينه لاحقاً بإضافة تحليل التنقّل الطيفي (Spectral Flux) لاكتشاف حدود المقاطع.

> **تنبيه مهم:** عتبات القرار مُعايرة على هذا الاختبار. عند وصول **الصوت البشري الحقيقي**
> سنعيد المعايرة مرة واحدة على صوت الممثل (إجراء قياسي في الاستوديوهات).

## 5. نظام الصوت — بلا موسيقى (سياسة ثابتة)

⚠ **لا موسيقى على الإطلاق:** لا موسيقى تصويرية، لا لحن مقدمة، لا لحن خاتمة، لا إيقاع.
المسموح فقط: **حوار + مؤثرات + محيط**.

### 5.1 الطبقات المحيطية الخمس (إجرائية، ليست شريطاً مكرّراً)

| الطبقة | الوصف | المستوى (RMS) |
|---|---|---|
| `wind` | ريح خفيفة بمغلّف بطيء متغيّر | 0.047 |
| `engine_hum` | هَمهمة المحرك النظيفة (نغمة 58Hz + 3 توافقيات) | 0.234 |
| `turbine_whine` | أزيز مروحة الرياح النحاسية (620Hz + تعديل حلقي) | 0.073 |
| `wheel_rumble` | دمدمة العجلات المطاطية (70–320Hz + حبيبات 900–3200Hz) | 0.041 |
| `steam_hiss` | فحيح البخار النظيف بنفثات دورية (1.4/ثانية) | 0.044 |

كل طبقة تُصدَّر كملف مستقل (`stem_*.wav`) — أسلوب الاستوديو — فيسمح بتعديل أي طبقة دون لمس البقية.

**الطبقات تستجيب لحالة المشهد:** منحنى السرعة `speed_curve` يحرّك هَمهمة المحرك وأزيز المروحة
ودمدمة العجلات معاً — أي أن الصوت «يتسارع» فعلاً مع القاطرة، وليس شريطاً ثابتاً.

### 5.2 تفادي التغطية (Ducking)

عندما يتكلّم أحد، ينخفض مستوى المحيطي تلقائياً بنسبة 55% ثم يعود بسلاسة —
يضمن وضوح الحوار دون تدخل يدوي.

## 8. ما يعنيه هذا لسير العمل معك

**أنت ترسل:** نصّ الحلقة + ملفات الصوت المسجّلة (حوار كل شخصية)

**ما يحدث تلقائياً:**
```
ملف الصوت  →  audio_lipsync.analyze()  →  جدول تبديل الفم إطاراً بإطار
نصّ الحلقة  →  timeline.json            →  أوضاع الشخصيات، حركة القاطرة، الطبقات
                        ↓
                  render_shot()
                        ↓
        إطارات PNG  →  MP4  ←  مزج (حوار + محيطي بلا موسيقى)
```

**ما يحتاج قراراً بشرياً (لا أتخذه أنا):** التوقيت الكوميدي، الإيماءات الدرامية،
اختيار زوايا الكاميرا، وترتيب اللقطات.

## 9. حدود النظام الحالية — بصراحة تامة

| البند | الحالة |

| جودة الرسم في الطبقات | ⚠️ نموذج تقني أولي (متجهي نظيف ومتسق 100%) — يحتاج تجميلاً فنياً |

| الصوت البشري الحقيقي | ⏳ بانتظار ملفاتك |
